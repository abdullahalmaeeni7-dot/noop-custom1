# App screen previews

33 browser-rendered design approximations informed by the current SwiftUI source. These are NOT native iPhone screenshots. Example health and food logs are illustrative. Missing measurements, unopened camera, disconnected account/device and empty activity/weight states remain explicit. Native layout, controls and fonts can differ; this gallery does not establish pixel parity or iOS runtime success.

Open index.html after extracting this ZIP, then select any image to view the full-length version. Four contact sheets provide an overview. File operations and permission dialogs supplied by iOS are not separately fabricated.

Implemented pages and forms are covered. Private Coach/community services, Heart Screener/ECG, Blood Pressure Insights and Women's Health are not implemented as working screens and are not invented here. Healthspan/WHOOP Age appears only as unavailable inside Health Monitor. The Live widget image is a component layout approximation, not a real Lock Screen capture.

The actual app source is unchanged by this gallery. No AI provider calls, real account sign-in, connected sensor, or camera photograph was used to generate these images.
